# 组件通信与状态管理实现方案

## 一、项目现状分析

### 1. 组件层次结构
```
App -> Layout -> ProductList
          -> ProductDetail

ProductList -> Filter
            -> ProductCard
            -> Pagination
```

### 2. 现有问题
- 组件间数据共享困难
- 筛选条件无法跨组件传递
- 购物车数据没有全局管理
- 商品列表数据没有统一存储

## 二、状态管理方案

### 1. 技术选型
- **状态管理库**：Zustand（已在package.json中配置，轻量、简单易用）
- **组件通信**：Props + 状态管理库

### 2. Store设计

#### 2.1 productStore - 商品相关状态
```typescript
interface ProductStore {
  // 商品列表
  products: Product[];
  // 商品详情
  productDetail: ProductDetail | null;
  // 筛选条件
  filters: {
    category: string[];
    price: string[];
    sales: string[];
  };
  // 分页信息
  pagination: {
    current: number;
    pageSize: number;
    total: number;
  };
  // 方法
  fetchProducts: () => Promise<void>;
  fetchProductDetail: (id: string) => Promise<void>;
  setFilters: (filters: Partial<ProductStore['filters']>) => void;
  resetFilters: () => void;
  setPagination: (pagination: Partial<ProductStore['pagination']>) => void;
}
```

#### 2.2 cartStore - 购物车相关状态
```typescript
interface CartStore {
  // 购物车商品
  items: CartItem[];
  // 总商品数
  totalItems: number;
  // 总价格
  totalPrice: number;
  // 方法
  addToCart: (product: Product, quantity: number) => void;
  removeFromCart: (productId: string) => void;
  updateQuantity: (productId: string, quantity: number) => void;
  clearCart: () => void;
}
```

## 三、组件通信设计

### 1. 父传子：Props
- **ProductList -> ProductCard**：传递商品数据
- **ProductList -> Pagination**：传递分页信息和回调
- **ProductDetail -> Image**：传递图片数据

### 2. 子传父：状态管理库
- **Filter -> 全局**：使用`productStore.setFilters()`更新筛选条件
- **ProductCard -> 全局**：使用`cartStore.addToCart()`添加商品到购物车
- **Pagination -> 全局**：使用`productStore.setPagination()`更新分页信息

### 3. 跨组件通信：状态管理库
- **Filter -> ProductList**：共享筛选条件
- **ProductDetail -> Cart**：共享购物车数据
- **Navbar -> Cart**：显示购物车商品数量

## 四、实现步骤

### 1. 创建Store文件
- `src/stores/productStore.ts` - 商品相关状态
- `src/stores/cartStore.ts` - 购物车相关状态

### 2. 实现productStore
- 定义商品数据接口
- 实现商品列表获取和筛选
- 实现商品详情获取
- 实现筛选条件管理

### 3. 实现cartStore
- 定义购物车数据接口
- 实现添加、移除、更新商品数量
- 实现计算总价和总数量

### 4. 修改现有组件
- **Filter.tsx**：使用productStore管理筛选条件
- **ProductList.tsx**：使用productStore获取商品列表
- **ProductCard.tsx**：使用cartStore添加商品到购物车
- **Pagination.tsx**：使用productStore管理分页

### 5. 测试组件通信
- 测试筛选条件是否能影响商品列表
- 测试添加商品到购物车是否能更新购物车数量
- 测试分页是否能正确更新商品列表

## 五、预期效果

1. **筛选功能**：
   - 点击Filter组件的筛选条件，ProductList组件能实时更新
   - 筛选条件能持久化存储

2. **购物车功能**：
   - 点击ProductCard的添加购物车按钮，购物车数量更新
   - 购物车数据能在多个组件间共享

3. **分页功能**：
   - 点击Pagination组件，ProductList组件能显示对应页的商品
   - 分页信息能在多个组件间共享

## 六、技术优势

1. **Zustand优势**：
   - 轻量，无外部依赖
   - API简单，学习成本低
   - 支持TypeScript
   - 性能优化，组件只订阅相关状态

2. **组件通信优势**：
   - 清晰的数据流向
   - 减少props drilling
   - 便于维护和扩展
   - 支持跨组件通信

这个方案能有效解决当前项目的组件通信和状态管理问题，实现数据的全局共享和组件间的高效通信。

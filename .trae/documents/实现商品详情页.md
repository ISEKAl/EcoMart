# 商品详情页实现计划

## 1. 需求分析
实现一个完整的商品详情页，包含以下布局和功能：
- 左侧：商品图片轮播区 + 缩略图区域
- 右侧：规格选择区
- 最下方：推荐商品栏（4-6个商品卡片）

## 2. 组件规划

### 2.1 现有组件
- **ProductCard**：已实现，可直接用于推荐商品栏

### 2.2 新增组件
无需创建新的独立组件，直接使用 ArcoDesign 组件库的现有组件：
- **Carousel**：用于商品图片轮播
- **RadioGroup**：用于规格选择
- **Select**：用于数量选择
- **Grid**：用于推荐商品布局
- **Descriptions**：用于商品规格参数展示

## 3. 实现步骤

### 3.1 实现商品详情页组件
- 文件：`src/components/pages/ProductDetail.tsx`
- 功能：
  - 导入所需的 ArcoDesign 组件
  - 定义商品详情接口和推荐商品接口
  - 实现商品详情页的完整布局

### 3.2 实现左侧轮播区
- 使用 ArcoDesign 的 `Carousel` 组件
- 显示商品主图
- 支持自动播放和手动切换

### 3.3 实现缩略图区域
- 位于轮播图下方
- 显示所有商品图片缩略图
- 点击缩略图可切换轮播图
- 高亮显示当前选中的缩略图

### 3.4 实现右侧规格选择区
- 商品基本信息（价格、销量等）
- 规格选择（颜色、版本等）
- 数量选择器
- 加入购物车和立即购买按钮

### 3.5 实现推荐商品栏
- 使用 `Grid` 布局，每行4个商品
- 使用现有的 `ProductCard` 组件
- 显示4-6个推荐商品

### 3.6 添加模拟数据
- 商品详情数据
- 商品图片数据
- 规格选项数据
- 推荐商品数据

### 3.7 样式优化
- 响应式设计，适配不同屏幕尺寸
- 流畅的动画效果
- 清晰的视觉层次

## 4. 技术栈
- React 19
- TypeScript
- ArcoDesign 组件库
- CSS-in-JS（内联样式）

## 5. 布局结构
```
商品详情页
├── 返回按钮
├── 商品标题和价格
├── 核心内容区（flex布局）
│   ├── 左侧轮播区
│   │   ├── 主轮播图
│   │   └── 缩略图区域
│   └── 右侧规格区
│       ├── 商品信息
│       ├── 规格选择
│       ├── 数量选择
│       └── 购买按钮
├── 规格参数区
├── 商品描述区
└── 推荐商品栏（Grid布局）
    └── 4-6个商品卡片
```

# 项目打包部署到公网计划（静态网站托管版）

## 1. 项目分析

* 项目类型：React + TypeScript + Vite 构建的电商平台

* 路由模式：BrowserRouter (history 模式)

* UI 框架：Arco Design

* 状态管理：Zustand

* 数据模拟：Mock.js

## 2. 打包步骤

### 2.1 执行打包命令

```bash
npm run build
```

该命令会执行 `tsc -b && vite build`，完成以下操作：

* TypeScript 编译检查

* 代码压缩和优化

* 静态资源打包

* 生成可部署的 `dist` 目录

### 2.2 验证打包结果

```bash
npm run preview
```

本地预览打包后的项目，确保功能正常。

## 3. 静态网站托管部署方案

### 3.1 选择静态托管平台

推荐以下平台，它们都支持 React Router history 模式：

* **Vercel**：对 React 项目支持最好，自动配置 history 模式

* **Netlify**：简单易用，支持自定义重定向规则

* **GitHub Pages**：免费，适合开源项目

### 3.2 Vercel 部署（推荐）

#### 3.2.1 准备工作

* 将代码推送到 GitHub/GitLab/Bitbucket 仓库

* 注册 Vercel 账号（可使用 GitHub 账号登录）

#### 3.2.2 部署步骤

1. 登录 Vercel 控制台

2. 点击 "Add New\..." → "Project"

3. 导入你的代码仓库

4. 配置项目：

   * Framework Preset：选择 "Vite"

   * Build Command：`npm run build`

   * Output Directory：`dist`

   * Root Directory：保持默认

5. 点击 "Deploy"

6. 等待部署完成，获得临时域名

7. 配置自定义域名（可选）

### 3.3 Netlify 部署

#### 3.3.1 部署步骤

1. 登录 Netlify 控制台

2. 点击 "Add new site" → "Import an existing project"

3. 导入你的代码仓库

4. 配置构建设置：

   * Build Command：`npm run build`

   * Publish Directory：`dist`

5. 点击 "Deploy site"

6. 配置 history 模式：

   * 在项目设置中找到 "Redirects and rewrites"

   * 添加重定向规则：

     ```
     /*    /index.html   200
     ```

### 3.4 GitHub Pages 部署

#### 3.4.1 配置 Vite

修改 `vite.config.ts`，添加 `base` 配置：

```typescript
export default defineConfig({
  // ...
  base: '/your-repo-name/', // 替换为你的仓库名称
  // ...
})
```

#### 3.4.2 安装部署工具

```bash
npm install -D gh-pages
```

#### 3.4.3 添加部署脚本

在 `package.json` 中添加：

```json
{
  "scripts": {
    // ...
    "deploy": "gh-pages -d dist"
  }
}
```

#### 3.4.4 部署到 GitHub Pages

```bash
npm run build
npm run deploy
```

#### 3.4.5 配置 GitHub Pages

* 进入仓库设置

* 找到 "Pages" 选项

* 选择 "Deploy from a branch"，分支选择 `gh-pages`，目录选择 `/ (root)`

* 保存设置

### 3.5 处理 history 模式路由

不同平台处理 history 模式的方式：

* **Vercel**：自动支持，无需额外配置

* **Netlify**：需要添加重定向规则 `/*    /index.html   200`

* **GitHub Pages**：

  * 方法 1：使用 HashRouter 替代 BrowserRouter

  * 方法 2：添加 `404.html` 文件，内容与 `index.html` 相同

  * 方法 3：使用第三方库如 `react-router-gh-pages`

## 4. 部署验证

1. 访问分配的域名，检查网站是否正常加载

2. 测试路由跳转，确保 history 模式正常工作

3. 测试各种功能，确保所有功能正常

## 5. 持续部署配置

所有平台都支持持续部署：

* 当你向代码仓库推送新代码时，平台会自动重新构建和部署

* 无需手动执行部署命令

## 6. 注意事项

* 确保 `package.json` 中的 `homepage` 字段配置正确（GitHub Pages 需要）

* 生产环境建议关闭 Mock.js，连接真实后端服务

* 静态资源路径要使用相对路径，避免硬编码绝对路径

* 配置自定义域名时，需要在域名服务商处添加 DNS 记录

## 7. 域名和 HTTPS 配置

所有主流静态托管平台都提供免费的 HTTPS 证书：

* **Vercel**：自动配置 HTTPS，支持自定义域名

* **Netlify**：自动配置 HTTPS，支持自定义域名

* **GitHub Pages**：为自定义域名配置 HTTPS 需要额外步骤

## 8. 性能优化建议

* 启用 Gzip/Brotli 压缩（平台默认支持）

* 配置适当的缓存策略

* 优化图片资源，使用 WebP 格式

* 启用 CDN 加速（平台默认支持）
